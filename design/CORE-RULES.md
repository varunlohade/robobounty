# CrashLab design rules (chosen 2026-11-06, set A of round 2)

Owner's words: "make it like a normal website with white and palantier font and stuff make it feel supa fking rich and copy those kaggle for the style but not entierly".
The owner delegated the final pick to steve: "Choose what you think is correct." Steve chose set A plus the "What unlocks the reward?" block from set B.

- White page, near-black ink, one quiet deep green accent, a failure red only for failures.
- Palatino for headings and body. Tabular numbers in tables.
- Normal site header. Kaggle-like structure: bounty list, bounty page with tabs, ranked table. Do not copy Kaggle's name, logo, colours or wording.
- Real simulator footage only. Real numbers on real pages. Sample data must say so.
- Say "replay the recorded run", never "reproducible from a seed".
