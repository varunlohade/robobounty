# CrashLab: visual references

Six real pages, each with one idea to steal. All six are in one image: [inspiration/grid.png](inspiration/grid.png).

## 1. Euro NCAP: Tesla Model Y result
- URL: https://www.euroncap.com/assessments/tesla/model+y/1181/
- Screenshot: [inspiration/01-euroncap.png](inspiration/01-euroncap.png)
- Steal: One star verdict on top, then four big percent scores, with crash-film thumbnails beside them, so a judge reads the result in three seconds.

## 2. IIHS: 2024 Toyota Camry ratings
- URL: https://www.iihs.org/ratings/vehicle/toyota/camry-4-door-sedan/2024
- Screenshot: [inspiration/02-iihs.png](inspiration/02-iihs.png)
- Steal: A failure list where each test name links to its detail and ends in one colored letter grade, so the one bad result jumps out.

## 3. PX4 Flight Review: public flight log
- URL: https://review.px4.io/plot_app?log=2803bce2-8b81-4b1a-b31c-52cbe06f3b9b
- Screenshot: [inspiration/03-px4-flight-review.png](inspiration/03-px4-flight-review.png)
- Steal: The plain report header (hardware, duration, max speed, max tilt) above a path colored by flight mode: a dry evidence sheet that feels trustworthy.

## 4. Foxglove: robot data visualization
- URL: https://foxglove.dev/product/visualization
- Screenshot: [inspiration/04-foxglove.png](inspiration/04-foxglove.png)
- Steal: Many time-synced panels on one scrubber, plus the loud green status block, to show what the robot saw at the moment it failed.

## 5. Frame.io: review and approval
- URL: https://frame.io/features/review-and-approval
- Screenshot: [inspiration/05-frameio.png](inspiration/05-frameio.png)
- Steal: Large video on the left and timecode-tagged notes on the right, so each failure note jumps to its exact moment in the replay.

## 6. Endcap: type-led studio site (found on Awwwards)
- URL: https://endcap.design/
- Screenshot: [inspiration/06-endcap.png](inspiration/06-endcap.png)
- Steal: Huge black type on one flat acid color, so "Crash tests made cars safe" reads from the back of a demo room.
